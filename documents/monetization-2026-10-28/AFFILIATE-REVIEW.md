# Affiliate review — October 28, 2026

Firecrawl is a relevant candidate for the existing web-scraping guide, but this
change does not activate affiliate monetization. There is no verified EveryMCP
partner account, approved link, referral receipt or payout evidence in this lane.
No application, signup, account grant or disclosure of user information occurred.

## Required provider lookup

Used the installed Stripe Directory skill before provider research. Stripe CLI
1.55.3 and Directory 0.3.5 were installed in scratch storage; the plugin initially
could not write the read-only home config directory, then installed with its
configuration root in `/tmp/everymcp-stripe-config`. No Stripe login or key was
used. `stripe directory search --help` established the syntax.

- `Firecrawl`, JSON, limit 3: returned Firecrawl, username `firecrawl`, a Stripe
  App and a provisioning next action. No next action was executed.
- `Microsoft Playwright`, JSON, limit 3: no result. The broader `browser automation`
  search returned Browserbase, tinyfish and KERNEL, not Microsoft's package.
- `Model Context Protocol Fetch`, JSON, limit 3: returned adjacent commercial
  providers, not the reference Fetch project. Publisher repositories were used
  for package-level evidence after these insufficient Directory matches.

Directory establishes a discovery/engagement path, not affiliate eligibility,
commission, product compatibility or EveryMCP participation.

## Primary-source program findings

[Firecrawl program page](https://www.firecrawl.dev/affiliates), including its FAQ:
Tool directories are invited to apply; review is described despite the headline's
no-approval wording. It advertises 25% during the first 12 months and 15% afterward.
Enterprise contracts are excluded. Self-referrals, bots, unauthorized resellers
and previously banned accounts are ineligible. Paid search is prohibited;
organic tutorials, articles and newsletters are described as acceptable.

The provider-linked [Dub program portal](https://partners.dub.co/firecrawl)
instead lists 15% per sale for the customer's lifetime. This conflicts with the
first-year headline. Treat 15% and 25% as alternative sensitivity assumptions,
not a confirmed payable rate. Eligibility as a tool-directory category does not
prove this site's acceptance. Attribution window, validation/reversals, exact
payout threshold/timing and the applicable contracted rate remain unverified.
An authorized owner would need to resolve these before activating referral links.

## Publication decision

The guide and free worksheet contain normal publisher links without affiliate
parameters or redirects. They disclose EveryMCP's own starter-kit offer. They
make no provider endorsement, performance, affiliate approval or commission
claim. No affiliate revenue is attributed to these ordinary links.

If a future owner supplies an approved referral URL and applicable terms,
review that exact URL and the relevant page disclosure together. This draft
contains no dummy affiliate identifier or invitation to bypass program rules.
